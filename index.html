Python binary search on answer
def binary_search_on_answer(low, high, ok):
    ans = -1
    while low <= high:
        mid = low + (high - low) // 2
        if ok(mid):
            ans = mid
            high = mid - 1
        else:
            low = mid + 1
    return ans
OS and DBMS
Download PDF
Operating systems
  • Process vs thread: a process owns memory; threads share it and need locks.
  • Scheduling: FCFS, SJF, Round Robin (time quantum).
  • Deadlock: mutual exclusion, hold and wait, no preemption, circular wait.
  • Virtual memory: paging; thrashing is excessive swap I/O.
DBMS
  • Joins: inner, left, right, full.
  • ACID: atomicity, consistency, isolation, durability.
  • Indexes: faster reads, slower writes, extra storage.

    How this site works

    Is this a backend product?

    No. Everything runs in the browser. Sign-in, checklists, bookmarks, and the tracker use localStorage. Treat it as a personal study desk, not a hosted account system.

    Why Gmail?

    The current gate is a simple Gmail-format check so the library is not a completely open dump. It is not Google OAuth unless you later add a client ID.

    What should I do first?

    If a drive is within eight weeks, use the sprint plan. Otherwise start mastery, log companies in the tracker, and pick one project from the library that you can explain in an interview.
